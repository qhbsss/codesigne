## 目标与下一个大方向

固定公共基线下：

S = 1000 √(30996995 × 1302032 / (TP × TD))。

八万分要求 TP×TD ≤ 6306106155.2875。63872 版本还需乘积下降 36.25%；只做 1% 左右的循环微调不足。250000×25000 可得约 80358 分，260000×24000 可得约 80422 分，这些是预算，不是已经测得的方案。

必须同时建模：工作组的私有 RF/SH 容量及存活区间、SM 驻留上限、MMA 的阵列复制读量、DMA 队列、跨组全部写入事件、HBM 通道与 multicast 同周期条件、峰值功耗和程序 8 MiB 上限。只按 FLOP 和总带宽估计会误判。

下一步的较大方向是把 QKV、注意力、WO/归一化、FFN 放到不同组，按真实行块事件流水，而不是在同一批组间反复覆盖权重并等待全层。必须解决 64 组驻留、W2 全权重与 KV 的冲突，以及早期消费者对 KV 前缀的真实依赖。当前尚未实现、验证这一完整流水，不能声称它能达到八万。

两类直觉方案不能直接当作收益：全 FFN 融合若每个 W1 的 K32 工作者写 W2 全列部分和，会把四个 K256 部分和变成 32 个 K32 部分和，部分和流量增加 8 倍；跨层无约束预取会破坏 multicast 并使功耗超限。要用实际驻留与流量公式筛掉这些代价后，再实施候选并做完整 grade。

W2 双缓冲完整结果相较 63460.97 分再减少 3951 个 P1 周期，D1 不变，分数提高约 0.65%。全部原始精评均保存。

8-bank 大块 W1 局部结果为 105711 周期，相较当前 W2 双缓冲第一层 81063 周期退化约 30.4%。指令数从29918降至26237，但单 SM 最大 SFU 忙碌从3072增至6008，向量忙碌从8824增至16326，RF读取从48598增至49622周期。DMA忙碌虽降低，无法抵消执行单元代价；无需继续完整精评该劣化候选。
