## 本轮方向

模型增加了指令内部 RF 读→计算→RF 写阶段、独立累加器、DMA 槽位、
冷缓存银行吞吐、HBM 通道与多播发射时序、RF 参数的生命周期。
纠正了上一轮将实际 NoC 忙周期当成不可压缩下界的错误。

得到的有效新变换包括：

1. D1 将注意力的 max/sum 合并传输，W2 用独立 N64 输出块。
2. D1 将 LayerNorm 的统计计算与后续 GEMV 重叠。
   使用 $\mathrm{LN}(x)W=\rho[(x\odot\gamma)W-\mu(\gamma W)]+\beta W$，
   其中 $\rho=(\mathrm{var}(x)+\epsilon)^{-1/2}$。
   固定投影由程序从实际运行参数计算，不预计算特定 seed 的答案。
3. D1 用已不再需要的 RF β 参数位置保存固定投影和 b1，减少 SH/HBM 搬运。
4. P1 将 QKV 中的 K/V 直接写入规定的缓存位置，减少导出中间搬运。
   注意力 QK/PV 分块从 8 列/键扩大到 16。
5. P1 WO 使用两个独立 K 累加器，再做一次合并。
6. P1 最后一层 W2 权重保留在原工作组，另 32 个工作组执行新位置计算，
   到最后一层 W2 时复用保留权重。生产者、消费者和最后输出之间加入全组屏障。

所有浮点重排均需数值验证；公式等价本身不能代替验证。
